# 새 디자인과 검수 정책 연결

2026-11-09: 실제 도서관 LED(2046×768, 8000×3000mm, P4)에 맞춰 화면 틀을 꽉 채우고 의미 있는 글자를 최소 1u(약 20px)로 올렸다. QR은 모듈당 정수 픽셀(3px)로 그린다. 움직이는 구름은 최신 30개만 표시하고 개수·예보는 전체 기준이다. Windows ‘애니메이션 효과’ 설정과 무관하게 움직인다. 전체 화면 시간은 서버가 정한다. [도서관 노트북 운영](library-laptop-operation.md)

2026-11-05 팀 시안의 학생 작성 화면과 2400 × 800 전광판을 실제 React 화면에 적용했다. **Gemini 검수 정책을 우선하고 전체 화면 재생은 15초다.** [HTML 시안](../moodwall-design/README.md)은 시각 참고 자료이며 실제 서비스는 `frontend/src/`에서 실행한다.

## 실제 화면의 기준

| 항목 | 적용한 동작 |
| --- | --- |
| 학생 작성 | 크림 배경·큰 입력칸·파란 버튼·완료 카드·시스템 다크 모드. 30 grapheme와 서버의 최근 1시간 한도 유지 |
| 입력 | v2 `content`만 전송. 이모지·감정·검수 결과를 학생이 지정하지 않음 |
| 검수 | ALLOW·BLOCK·UNCERTAIN·SUPPORT. SUPPORT는 비공개 도움과 원문 미리보기 제거. 자동 벌점·3회 경고·5회 정지 없음 |
| 접수 완료 | ‘메시지를 보냈어요!’ 이후 표시 여부 결정. 표시 시간은 서버가 정함(기본 15초, 대기 시 최소 8초). 접수 응답만으로 송출을 약속하지 않음 |
| 전광판 | 2:1~3:1 화면을 꽉 채움(실측 도서관 LED 2046×768)·로컬 구름 16종·감정별 낮/밤 색·전체 화면 효과·LED 정수 배율 QR |
| 감정 | 서버의 8개 `sceneId`만 고정 팔레트에 매핑. 7감정과 중립색. 모델은 임의 CSS·색상·자산 주소를 지정하지 않음 |
| 통계 | ‘이 화면에 남은 기분 기준’. 현재 노트북의 말풍선 집계이며 하루 전체 제출 수가 아님 |
| 낮과 밤 | 한국 시각의 고정 시간대를 사용한 효과. 실제 일출·일몰·날씨 측정이 아님 |
| 복구 | QR·CSRF·동일 요청 복구·지원/신고·재생 임대·숨김·기기 해지·자정 정리·직원 설정 화면 유지 |

검수와 자산 준비를 마친 글부터 기존 첫 프레임 승인·15초 하한·완료 ACK 경로로 재생한다. 시안의 데모 자동 순환은 사용하지 않는다. Jua·Noto Sans KR과 구름 SVG는 빌드에 포함하므로 Google Fonts 접속이 필요 없다.

## 감정별 구름 색 연결

Gemini는 검수만 맡는다. 선택적으로 기존 학생 모델의 **감정 추론만** Gemini ALLOW 뒤에 실행한다. 모델의 ‘부적절’ 분류나 일반적인 추론 오류는 중립색이 되고 Gemini 판정을 바꾸지 않는다. 멈춘 추론은 전체 처리 시간 경계에서 기술 실패로 비공개 종료될 수 있다. 모델을 지정하지 않은 실행도 중립색으로 동작한다. [감정 모델 연결과 검증](gemini-emotion-integration.md)을 따른다.

이미 준비한 로컬 bundle이 있다면 저장소 루트에서 실행한다.

```powershell
python scripts/setup_gemini.py --start --emotion-model models/student-v0
```

실행기는 모델을 다운로드하지 않는다. 선택한 경로를 로컬 설정에 저장하고 다음 `--start`에서 재사용한다. API와 worker는 읽기 전용 bundle의 검증된 해시로 같은 릴리스를 사용하며 실제 추론 라이브러리와 모델은 worker에서만 로드한다. 키를 입력하면 시작 시 합성 확인이 실제 Gemini를 호출하므로 사용료가 발생할 수 있다.

## 화면 확인

[프론트 가이드](../frontend/README.md)와 [Gemini 실행 가이드](gemini-moderation-implementation.md)의 기존 운영자 생성·장치 등록·접수/송출 재개 절차를 따른다.

- `/join#ticket=…`, `/student`: 작성·접수 완료·수정·비공개 지원·통신 오류 복구
- `/display`: 대기·7감정과 중립색·15초 전체 화면·낮/밤·실제 QR
- `/display/setup`: 직원의 연결 확인과 장치 등록
- `/operator`: 검수 상태·접수/송출 중단과 재개·신고·숨김

기온·강수·천문 API는 연결하지 않았고 예시 값을 실제 측정값처럼 표시하지 않는다. 실제 Gemini의 한국어 판정 품질, 감정 분류 품질, 학교 노트북과 HDMI 화면의 수락은 각각 별도 확인 대상이다.

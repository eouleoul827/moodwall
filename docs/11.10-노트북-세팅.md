# 11.10 노트북 세팅

작성: 2026-11-10. 도서관 노트북(Windows 10/11)에 무드월 서버와 LED 전광판(2046×768)을 처음 설치하는 절차다. 노트북에 연결한 코딩 에이전트(Codex 등)와 사람이 같이 보도록 썼다. 각 단계에 누가 하는지 표시했다.

- **[사람]**: GUI 클릭, 웹 로그인, 비밀값 입력. 에이전트는 사람에게 요청하고 끝났는지 확인만 한다.
- **[에이전트]**: 에이전트가 실행할 수 있는 명령이다. 실행 뒤 "확인" 항목으로 결과를 검증한다.

배경 설명은 [library-laptop-operation.md](library-laptop-operation.md)에 있다. 이 문서는 실행 순서만 다룬다.

## 에이전트 규칙 (반드시 지킬 것)

1. **비밀값을 출력하거나 기록하지 않는다.** 대상은 `.env`의 내용, `MOODWALL_GEMINI_API_KEY`, DB 비밀번호, 운영자 비밀번호, Tailscale 인증 키다. 로그, 커밋, 채팅 어디에도 남기지 않는다.
   - `.env`는 통째로 `cat`/`Get-Content` 하지 않는다. 확인이 필요하면 키 이름만 본다. 예: `Select-String .env -Pattern '^MOODWALL_PUBLIC_ORIGIN='`
2. **`.env`는 커밋하지 않는다.** 이미 `.gitignore`에 있다. 개발 PC의 `.env`를 복사해 오지 않는다.
3. **Gemini 키는 사람이 직접 입력한다.** `setup_gemini.py`가 숨김 입력으로 묻는다. 에이전트가 키를 인자나 환경변수로 넘기지 않는다.
4. 관리자 권한이 필요한 명령은 표시해 두었다. 권한이 없으면 사람에게 관리자 PowerShell에서 실행해 달라고 요청한다.
5. 저장소의 코드, 설정, 이 문서를 고치는 것은 이번 설치 범위가 아니다. 문제가 보이면 고치지 말고 사람에게 보고한다.
6. 각 단계의 "확인"이 통과하지 않으면 다음 단계로 넘어가지 않는다.

## 0. 준비물 [사람]

- Tailscale 무료 계정(Google 로그인). 공개 주소의 주인이 되므로 인수인계할 사람을 정해 둔다.
- Gemini API 키: 이미 받은 키, 개발 PC `.env`의 `MOODWALL_GEMINI_API_KEY` 값이다. 결제가 연결된 계정의 키여야 한다(무료 등급은 입력 내용이 Google 서비스 개선에 쓰일 수 있다).
- 노트북 관리자 비밀번호, 직원이 쓰는 Windows 계정 이름.
- LTE 휴대폰. 바깥 접속은 학교 Wi-Fi가 아니라 LTE로 확인한다.

## 2. 프로그램 설치

에이전트가 `winget`으로 설치할 수 있다(관리자). `winget`이 없거나 실패하면 사람에게 링크로 설치를 요청한다.

```powershell
winget install --id Git.Git -e --accept-source-agreements --accept-package-agreements
winget install --id Python.Python.3.12 -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Docker.DockerDesktop -e
winget install --id Tailscale.Tailscale -e
```

- Docker Desktop 설치 뒤 **재부팅**한다.
- **[사람]** 재부팅 뒤 할 일:
  - Docker Desktop을 열어 약관에 동의한다.
  - Settings → General에서 **Start Docker Desktop when you sign in**을 켜고, **Open Docker Dashboard when Docker Desktop starts**를 끈다.
- **[사람]** Tailscale을 실행해 0의 계정으로 로그인한다.
- **[에이전트(관리자)]** 직원 계정이 관리자가 아니면 `docker-users` 그룹에 추가한다. 직원 계정은 로그아웃했다가 다시 로그인해야 적용된다.
  ```powershell
  net localgroup docker-users "<직원계정이름>" /add
  ```

**확인** (새 PowerShell 창에서. 각각 버전이 나오면 통과. Python은 3.12, Node는 22 이상)
```powershell
git --version; python --version; node --version; docker version --format '{{.Server.Version}}'; tailscale version
```

## 4. 무드월 서버

```powershell
git clone https://github.com/eouleoul827/moodwall.git C:\moodwall
cd C:\moodwall
```

**4.1 [사람이 입력, 에이전트가 실행 가능]** 첫 설정을 한다. 이 명령은 대화형이라, 에이전트가 숨김 입력을 대신할 수 없으면 사람이 직접 실행한다.
```powershell
python scripts/setup_gemini.py --start --create-operator --operator-name admin
```
- `Gemini API key (hidden):`에서 **사람이** 키를 붙여 넣는다.
- 이어서 운영자 `admin`의 비밀번호를 두 번 입력한다. 이것도 사람이 한다.
- 이 명령이 하는 일: `.env` 생성(새 비밀값 자동 생성), 화면 빌드(`npm ci`, `npm run build`), DB 마이그레이션, 전광판 초기화, 운영자 생성, 개발 구성으로 시작.

**4.2 [에이전트]** `.env`의 `MOODWALL_PUBLIC_ORIGIN` 한 줄만 `<ORIGIN>`으로 바꾼다. 다른 줄은 건드리지 않는다.
```powershell
$origin = 'https://moodwall-library.<tailnet>.ts.net'   # 3의 실제 값
$path = 'C:\moodwall\.env'
$lines = [IO.File]::ReadAllLines($path)
if (-not ($lines -match '^MOODWALL_PUBLIC_ORIGIN=')) { $lines += "MOODWALL_PUBLIC_ORIGIN=$origin" }
$lines = $lines -replace '^MOODWALL_PUBLIC_ORIGIN=.*$', "MOODWALL_PUBLIC_ORIGIN=$origin"
[IO.File]::WriteAllLines($path, $lines, (New-Object Text.UTF8Encoding($false)))
Select-String $path -Pattern '^MOODWALL_PUBLIC_ORIGIN='
```

**4.3 [에이전트]** 도서관 구성(운영 모드)으로 다시 시작한다.
```powershell
cd C:\moodwall
docker compose -f compose.yaml -f compose.frontend.yaml -f compose.gemini.yaml -f compose.library.yaml up -d --build api worker
docker compose -f compose.yaml -f compose.frontend.yaml -f compose.gemini.yaml -f compose.library.yaml ps
```

**확인**
- `ps`에서 `api`가 `healthy`, `worker`와 `db`가 `running`이면 통과.
- 에이전트가 `Invoke-WebRequest "$origin/api/health/live" -UseBasicParsing`을 실행해 200이 나오면 통과.
- **[사람]** LTE 휴대폰으로 `<ORIGIN>/operator`를 열고 `admin`으로 로그인한다. 처음에는 공개까지 최대 10분 걸릴 수 있다.
- 운영 모드는 `MOODWALL_PUBLIC_ORIGIN`이 https가 아니면 api가 시작을 거부한다. api가 계속 재시작하면 `docker compose ... logs api --tail 50`을 보되, 비밀값이 섞인 줄은 출력하지 않는다.

## 5. 전광판과 직원 아이콘 (직원 Windows 계정에서)

| # | 누가 | 할 일 |
| --- | --- | --- |
| 5.1 | 사람 | HDMI 연결 → `Win + P` → **두 번째 화면만** |
| 5.2 | 사람 | 설정 → 디스플레이: **2046 × 768**(없으면 2048 × 768), 배율 **100%**. 목록에 없으면 그래픽 드라이버의 사용자 지정 해상도. 잘리거나 늘어나 보이면 사진을 남기고 보고 |
| 5.3 | 사람 | 화면 보호기 끄기, 알림 방해 금지, 접근성 → 시각 효과 → 애니메이션 효과 켜기 |
| 5.4 | 에이전트 | 직원 아이콘 설치(아래). **직원 계정 세션에서** 실행해야 그 계정의 바탕화면과 시작프로그램에 생긴다 |
| 5.5 | 사람 | 전광판 등록(아래 5단계) |

```powershell
# 5.4 먼저 검증만, 그다음 설치
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\moodwall\ops\display-launcher\Install.ps1" -ServerRoot "C:\moodwall" -PlanOnly
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\moodwall\ops\display-launcher\Install.ps1" -ServerRoot "C:\moodwall" -AutoStart
```
- 설치 도구는 다음 경우 이유를 한국어로 출력하고 종료 코드 1로 끝난다. 이유를 사람에게 그대로 전달한다.
  - `.env` 주소가 이 노트북의 Tailscale 주소와 다르다.
  - Tailscale이 로그인되어 있지 않다.
  - Funnel이 꺼져 있다.
  - `frontend/dist`가 없다.
- 성공하면 바탕화면에 **무드월 켜기**, **무드월 끄기**, **무드월 직원 설정·점검**이 생긴다.

5.5 전광판 등록 [사람]
1. **무드월 켜기**를 누른다. 로고만 보이면 정상이니 `Alt + F4`로 닫는다.
2. **무드월 직원 설정·점검** → **등록·설정 열기**를 누른다.
3. 휴대폰 `<ORIGIN>/operator`에서 등록 코드를 발급해 노트북에 입력한다.
4. 운영자 화면에서 **접수 재개**와 **송출 재개**를 누른다.
5. 설정 창을 닫고 **무드월 켜기**를 다시 누른다.

장치 등록은 사용하는 동안 자동으로 연장된다(마지막 사용 후 180일). 180일 넘게 안 켰거나 운영자가 해지했을 때만 다시 등록한다.

## 7. 문제 해결

| 증상 | 확인 순서 |
| --- | --- |
| 아이콘 설치가 Tailscale 때문에 실패 | `tailscale status`(로그인), `tailscale funnel status`(on, 127.0.0.1:8000), `.env`의 `MOODWALL_PUBLIC_ORIGIN`과 `Self.DNSName` 일치 여부 |
| 휴대폰에서 주소가 안 열림 | Docker Desktop 실행 여부 → `compose ps` → `tailscale funnel status` → 처음이면 10분 대기 |
| 켜기에서 "Tailscale이 꺼져 있어요" | 사람이 Tailscale 아이콘 → Connect. 반복되면 Run unattended 설정과 key expiry 확인 |
| 글이 계속 검수 대기 | worker 로그의 Gemini 연결 오류, 학교 웹필터 |
| 전광판에 로고만 | 직원 설정·점검 → 진단. 장치 해지·만료면 5.5 재등록 |
| api가 계속 재시작 | 운영 모드 시작 조건: `MOODWALL_PUBLIC_ORIGIN`이 https, 분석기가 `fake`가 아님(Gemini 설정 완료), `MOODWALL_SECRET_KEY`·`MOODWALL_QR_KEY`가 `change-`로 시작하지 않음. 4.1을 끝까지 했는지 확인 |

## 8. 직원용 안내 (출력해서 노트북 옆에)

**출근할 때**
1. 노트북을 켜고 로그인합니다.
2. 1~3분 기다리면 전광판에 무드월이 나옵니다.
3. 안 나오면 바탕화면의 **무드월 켜기**를 두 번 누릅니다.

**퇴근할 때**
1. 바탕화면의 **무드월 끄기**를 두 번 누릅니다.
2. "이제 노트북을 꺼도 괜찮아요"가 나오면 노트북을 끕니다.

**이럴 때는**
- "Tailscale이 꺼져 있어요": 오른쪽 아래 Tailscale 아이콘 → **Connect** → **무드월 켜기**를 누릅니다.
- "무드월을 켜지 못했어요": 노트북을 다시 시작하고 **무드월 켜기**를 누릅니다. 그래도 안 되면 담당자에게 알립니다.
- 로고만 계속 보이면: **무드월 끄기** → **무드월 켜기**를 누릅니다. 10분 뒤에도 그대로면 담당자에게 알립니다.
- 이상한 글이 보이면: 담당자에게 알립니다.

**하지 말아 주세요:** 전광판 위에 다른 창 띄우기, 브라우저 데이터 지우기, 프로그램 삭제, 덮개를 닫아 치우기.

출력용 Word 버전(직원 안내 한 장 포함)은 설치 담당자의 바탕화면에 있는 `무드월 도서관 설치 안내.docx`다.

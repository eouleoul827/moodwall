# 무드월 (Mood Wall) 디자인 시안

전주대학교 도서관 외부 전광판에 띄우는 감정 '구름' 프로젝트의 화면 시안입니다.
모든 파일은 브라우저에서 바로 열어볼 수 있습니다. (폰트는 인터넷 연결 시 Google Fonts에서 불러옵니다.)

**실제 서비스는 [새 디자인 연결](../docs/design-integration.md)과 [Gemini 검수 정책](../docs/gemini-moderation-design.md)을 따릅니다.** 이 폴더의 HTML은 전달받은 시각 참고 자료입니다. 실제 React 화면은 **15초** 재생이며, 아래 원본 시안의 1분·브라우저 필터·경고/정지 규칙은 실제 서비스에 적용하지 않습니다.

## 폴더 구성

```
display/
  display-idle.html        전광판 상시 화면 (구름, 무드 예보, 날씨 효과, 낮/밤 전환)
  display-fullscreen.html  새 구름 풀스크린 화면 (감정별 애니메이션, 1분 진행 바)
  runtime.js               두 화면을 그려주는 작은 스크립트 (같은 폴더에 두기)
mobile/
  index.html               QR로 접속하는 모바일 작성 페이지 (실제로 입력·전송 체험 가능)
assets/clouds/
  cloud-01~16.svg          구름 모양 16종 (흰색 단색, 색은 코드에서 지정)
  clouds.json              구름별 글씨 영역 정보 (가로 시작/끝, 세로 중심 — 0~1 비율)
```

## 전광판 화면 확인 방법

- 화면 오른쪽 아래 패널에서 낮/밤, 날씨, 감정을 바꿔볼 수 있습니다.
- 주소 뒤에 값을 붙여 바로 열 수도 있습니다.
  - `display-idle.html?theme=밤&weather=눈`
  - `display-fullscreen.html?emotion=축하`
- 패널 없이 보려면 `?kiosk` 를 붙이세요. (예: `display-idle.html?kiosk&theme=낮`)
- 화면은 창 크기에 맞춰 3:1 비율로 자동 확대·축소됩니다.

## 디자인 기준

| 항목 | 값 |
|---|---|
| 전광판 기준 크기 | 2400 × 800 (가로형 3:1 시안). 실제 도서관 LED는 2046 × 768(2.66:1)이며 React 화면이 빈 띠 없이 채운다 |
| 모바일 기준 크기 | 390 × 844 |

| 포인트 색 (모바일 버튼) | #2F6BEB |

### 감정별 애니메이션 (풀스크린)

축하 = 폭죽 · 기쁨/설렘 = 하트 · 응원 = 반짝임 · 슬픔 = 비 · 피곤/화남 = 없음

## 원본 시안의 정책 메모

- 구름 글자 수: 30자
- 작성 제한: 시간당 3회 (사용자에게 횟수는 안내하지 않고, 초과 시 상단 알림만 표시)
- 욕설 필터: 3회 경고, 5회 하루 정지 (차단된 단어는 알려주지 않음)
- 구름은 자정까지 전광판에 표시

실제 구현은 30 grapheme·서버의 최근 1시간 한도와 SUPPORT 우선 정책을 적용합니다. 자동 벌점은 없고 검수와 감정 분류를 분리합니다. 시안의 원문 localStorage 저장 기능은 실제 화면으로 옮기지 않았습니다.

## 개발 연결 메모

- 예시 데이터: 구름 문장, 감정 통계, 기온(12°C 등)은 모두 예시 값입니다.
- 날씨·기온: 기상청 단기예보 API → Node 서버에서 10~30분마다 받아 전광판에 전달
- 낮/밤: 한국천문연구원 출몰시각 API의 일몰·일출 기준, 20~30분에 걸쳐 전환 권장 (시안은 6초)
- 모바일의 횟수 제한·필터는 시안용으로 브라우저에서만 동작합니다. 실제 서비스에서는 서버에서 처리해야 합니다.
- 애니메이션은 `transform` / `opacity` 만 사용하세요.
